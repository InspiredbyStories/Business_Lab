# Business Lab Vault

Obsidian vault for collecting and organizing information from work with Claude.

## Structure

- `Inbox/` — new/unsorted notes land here first
- Project/topic folders are added as work starts on them

## Git

This vault is version-controlled with git and pushed to
https://github.com/InspiredbyStories/Business_Lab

Obsidian's local workspace/cache files are excluded via `.gitignore` — only
the actual notes and vault config worth sharing are tracked.
