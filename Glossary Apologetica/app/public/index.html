About

Glossary Apologetica version 1.0.0 — a private search and retrieval tool for your own research material. It does not use the internet, does not generate answers, and does not add anything to your results that you did not put into it.

This library is being served by the always-on background task, so there is nothing to close here — it keeps running so remote access stays available. Use "Remove Remote Access.ps1" if you want to turn that off.
